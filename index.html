The labels

Where each part comes from

  • Web source
    Web source Field values are copied verbatim from the museum's open access record — the frozen corpus, or the museum's API for a live lookup.
  • Offline renderer
    Offline renderer Summary and label text are drafted deterministically from the record. No model is called unless you ask for one.
  • AI generated
    AI generated Shown only when a model rewrite was requested — and only after it passed the same four checks as the offline draft.

When it says no. A record with a blank field, a catalogue number outside the corpus, or an out-of-scope question (value, authenticity, rights) is refused — the gap is reported, never filled in from elsewhere.
