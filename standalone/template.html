Exhibition labels, drafted one record at a time

A label draft you can check sentence by sentence.

Every label below was drafted by the real pipeline and embedded in this file at build time. Each sentence restates one field of the catalogue record it cites, and the checks on the right read the sentences back against that record. When a record cannot support a sentence, the tool refuses instead of guessing. No server, no network: open the file and it works.

Where each part comes from

  • Web source
    Web source Field values are copied verbatim from the museum's open access record, frozen into the corpus at fetch time.
  • Offline renderer
    Offline renderer Summary and label text are drafted deterministically from the record. No model is involved.
  • AI generated
    AI generated Shown only for a recorded model rewrite — and only because it passed the same four checks as the offline draft.

When it says no. A record with a blank field, a catalogue number outside the corpora, or an out-of-scope question (value, authenticity, rights) is refused — the gap is reported, never filled in from elsewhere.
