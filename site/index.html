AILT 9019 · Group 10

Label Desk

Draft exhibition labels from frozen museum records, and refuse when a required field is blank. Every sentence in a drafted label has to come from the catalogue record.

This file is a local page. It is not a published URL. GitHub Pages is not enabled on the repository. Do not treat a github.io address as this page.

Open the working collection

The working page is labeldesk.html in the repository root. Open that file directly. It does not need a host, a server, or an API key. Museum images need a network connection; the catalogue text stays available offline.

A drafted label the program actually prints

Local command on 16 Nov 2026: python3 -m labeldesk 14.40.377. Exit status 0.

STATUS  DRAFTED
Label   65 words (band 60–80)

  The object is titled "Vase". The catalogue dates it to 1713–22. The
  medium is recorded as "Porcelain with peach-bloom glaze (Jingdezhen
  ware)". Its place or culture is given as China. The credit line reads:
  Bequest of Benjamin Altman, 1913. Every sentence above restates one
  field of the catalogue record. No fact outside that record has been
  added. Draft for curator review, not an official record.

A refusal the program actually prints

Local command on 16 Nov 2026: python3 -m labeldesk 62.98.1. Exit status 3.

STATUS  REFUSED
Reason  missing_required_field

Record 62.98.1 has no object date. No label was drafted: a blank field
is not filled from outside the record. Supply the missing catalogue
information and run again.
